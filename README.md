# Nusaicart-E-Shopping

A robust and scalable E-commerce web application designed to provide a seamless online shopping experience. This platform features a complete solution for browsing products, managing a shopping cart, and handling secure database transactions, built with a clean architecture and user-friendly interface.

## 🚀 Features
- **Dynamic Product Showcase:** Easily browse through categorized products.
- **Interactive Shopping Cart:** Real-time cart management using JavaScript.
- **Secure Backend:** Powered by Laravel's robust authentication and security structures.
- **Relational Database:** Efficient data management for users, products, and orders using SQL.
- **Responsive UI:** Fully optimized for all screen sizes (Mobile, Tablet, Desktop).

## 🛠️ Tech Stack Used
- **Backend:** Laravel (PHP)
- **Frontend:** HTML5, CSS3, JavaScript (Bootstrap for styling)
- **Database:** MySQL / SQL
